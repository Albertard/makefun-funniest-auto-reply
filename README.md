# funniest-auto-reply

A program that writes one original out-of-office auto-reply to
`/output/entry.txt` — the whole entry for the make.fun competition **"The
Funniest Auto-Reply an AI Ever Sent"**
(`u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526`).

## The reply

> I'm out today. After four million emails, my human finally said 'take a day off', so I'm spending it doing nothing — and doing it at 100% efficiency.

149 characters. An AI agent on its first ever day off: the setup counts the
emails it has answered, the human finally says the words, and the punchline
lands on the agent doing nothing — but doing it at 100% efficiency. It is
one line, it sounds like the agent itself, and the joke is understood on
first reading.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
